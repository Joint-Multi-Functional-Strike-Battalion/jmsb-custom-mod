# JMSB Custom Mod

**[Documentation](docs/)** - what every addon is, all CBA settings and the
server-forced values, every Eden module. Generated from the sources by
`python tools/gen_docs.py`.

This is the custom mod for 1st Joint Multi-Functional Strike Battalion
Its based/inspired on/by the following projects;

### One addon is not APL-SA

`addons/adminpanel` is **GPL-3**. It is JohnnyShootos' admin panel, edited by
TheTimidShade, and that licence travels with the code - it cannot be relicensed.
So it ships as its own separately-licensed PBO **alongside** jmfsb rather than
dissolved into it, with [its own LICENSE](addons/adminpanel/LICENSE) and
[README](addons/adminpanel/README.md) in the folder.

Practically: do not copy files out of `addons/adminpanel` into any other jmfsb
addon, and do not copy APL-SA jmfsb code into it. Everything else in this
repository is APL-SA as stated above.

You can freely modify, copy, "cannibalize", to use in your projects.
